# Wi-Fi SoftAP Diagnostic

Archived source from 2026-11-04. Configures a visible DIY-Mic-Setup SoftAP on channel 6 at 192.168.4.1/24 with a four-client limit. The committed source uses a placeholder password; set a test password of at least eight characters before running it. The original credential is intentionally not stored in Git.

The build and upload succeeded. Runtime status reported AP mode and the configured IP, but repeated Ubuntu scans did not detect the SSID. No client association or HTTP request was completed. The cause was not isolated.
